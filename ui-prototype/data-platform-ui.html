订阅形态与模式
逻辑视图订阅
无数据流、无副本。订阅生效后自动开通 Trino 查询权限(Ranger 表/列/行级),子节点通过 SQL 联邦查询访问,权限与脱敏在查询时强制。适合探查、轻量消费。
物理同步订阅
数据实际分发到子节点。支持 Push(中央直连子节点 HTTP 接口,分钟级,中央维护推送位点)与 Pull(子节点 API 拉取,位点子节点维护)。适合核心业务与大批量离线。
分发模式
Push 主动推送
中央推送中心读 Iceberg 增量,批量同步完成后直连子节点 HTTP 接口投递。位点由中央维护,断点续传自动重推未确认区间。延迟 = 湖仓可见性(分钟级)。
Pull 订阅方拉取
子节点通过 API 主动拉取增量数据,位点由子节点自行维护,中央无状态。适合大批量离线同步。
投递配置
接口约定: 请求体含 (订阅ID, 逻辑表, 起始/结束水位, 密级标签(强制携带), 数据行);响应 200 视为确认,中央推进位点;失败重试,子节点不可达时水位暂停、数据留在 Iceberg 不积压。
Pull 模式无需投递配置。订阅生效后,子节点通过 GET /api/subscriptions/{id}/incremental?after={位点}&limit=1000 拉取增量,响应含新位点游标。位点由子节点维护,中央无状态。首次拉取可用 snapshot 参数获取全量快照。
逻辑视图订阅无需投递配置。生效后自动在 Ranger 创建查询策略(表/列/行级,继承接收密级上限),子节点通过 Trino 联邦查询访问。密级与脱敏在查询时强制,无数据副本。
