## 约定

- 模块内"总纲 + 子文档"结构:总纲给全貌与定论,子文档给细节(字段级/伪代码级/时序级);
- 新文档先落对应模块目录,再更新本 README 与模块内文档体系;
- 涉及存量代码的文档以代码事实为准,组件名精确。
