已验证能力清单(smoke 闭环,详见内核 README):

1. 提交 → 补 PENDING → 打分分配(CAS)→ watch 装载执行 → 快照上报闭环
2. 优雅退出(注销/让位/CAS 清理归属,spec/status 保留)
3. 崩溃接管:leader 转移 → 双窗口判死 → 保守交接 → 中间态换主可续 → 恢复消费
4. 锁机制:钉住分区 owner 崩溃不被回收(持续告警),TTL 到期自动解锁自愈
5. 定向迁移 MIGRATE_PIN:源主动停快通道 → 立即回收 → 定向分配,锁保留在目标
6. 卡死检测:快照停更超宽限(30s)→ 按交接模式迁移(起因=stuck)
7. 双确认判死:lease 过期但快照仍在更新 → SUSPECT 观察不判死(防误判双消费)
8. 再平衡:失衡(最忙>0.8 且差>0.3 持续 3 周期)→ 步进迁移(临时 TTL 锁定向)→ 自动解锁
9. 自动扩容:水位>0.8 持续 3 周期 → 尾部补分区(步长护栏最多翻倍)→ 分配闭环 + 事件
10. 逻辑缩容:水位<0.4 持续 6 周期 + 双闸门(downEnabled + 钩子声明)→ routeCut → DELETING 追平 → 清记录收敛不震荡
11. 任务注销:删 spec → DRAINING → 分区追平 → GONE + gone 事件(外壳释放资源)
12. 实例下架:DRAIN_INSTANCE → 不接新单逐轮迁出 → 迁空可安全关机;UNDRAIN 恢复且不回流
13. cpu 驱逐:进程 cpu>80 持续 3 周期迁出(与槽位失衡正交);目标选择跳过高负载实例
14. lag 实查追平:内置 AdminClient 按 ns 懒建,lag<100 连续 2 周期才清记录;无源回退 rps 护栏
15. 告警事件流:8 规则(SUSPECT/EXEC_STUCK/DRAIN_TIMEOUT/LAG_HIGH/ERROR_RATE/CAPACITY_FULL/MIGRATE_TIMEOUT/NO_INSTANCE),10min 去重,恢复覆盖 resolvedAt,滚动 200 条
16. 告警巡检:lag 高位与错误率(相邻帧差分)首现持续 3min 才报;PENDING>3 周期区分无实例/有候选失败
17. 暂停接单 PAUSE_INSTANCE/UNPAUSE_INSTANCE(独立意图键,不碰注册租约)
18. 调权 SET_WEIGHT(0.5~2.0 限幅,参与迁移目标打分)
19. 打分系数热配 /dcp/{ns}/scoring(α/β/γ/δ,缺省 0.4/0.3/0.2/0.1)
20. ns 默认规则 SET_RULES:运维 ops 消费 → 范围校验(0 < down < up ≤ 1、周期/冷却正整数、maxStep∈[1,3])→ 整包覆盖 /dcp/{ns}/rules 下一决策轮热生效 + 审计键 /dcp/audit/(端到端实测,非 smoke)
