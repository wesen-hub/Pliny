## 实现进度文档

`统一调度框架-实现进度.md` 是状态快照文档(非设计子文档):对照总纲 §十五落地路线六步逐项打状态,含框架内核已验证能力清单、三场景接入代码落点与端到端验证证据、管理面现状、验证环境状态、未落地事项。**实施(代码/验证)有进展即更新该文档**,设计与讨论定稿则更新总纲/子文档。

## 子文档维护约定

1. **不重复总纲**:总纲已有定论的只引用(§x),子文档展开"怎么做"的细节;
2. **细节级要求**:能写伪代码就写伪代码,能画时序就画时序,字段/状态/参数全部显式;
3. **与总纲互链**:总纲指明"详见子文档 x",子文档开头注明"承接总纲 §x";
4. **与代码对齐**:涉及存量代码(如 outlet 控制面)时,以代码事实为准,组件名精确;
5. **讨论定稿即更新**:讨论 → 定论 → 若影响全局先更新总纲 → 再更新对应子文档;初版内容在讨论中逐步修正。
